# Dashboard Displaying Income by Education Level Data Across Years in the United 

An interactive dashboard analyzing U.S. median household income by education level (2012–2023), built in both R Shiny and Retool.

This project explores how the median income of U.S. householders varies across their highest educational attainment levels and over time, with dynamic filtering and visualizations.

## Live Demo:

🔗 Retool App: https://nrashha26.retool.com/embedded/public/1d98e460-dd5d-43a2-b545-84b704dc2e9c/page1

🔗 Shiny (R) App: https://mariakhan.shinyapps.io/peer-project-econ-bros/

## Features:

- Dynamic filtering by year and education level
- Grouped bar charts comparing income trends over time
- Clean tabular view with built-in filtering
- Responsive UI design

## Tech Statck:

- R (Shiny, ggplot2, plotly)
- JavaScript (Retool queries, Plotly)
- SQL (data querying)
